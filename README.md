# 給家人的婚禮小冊

這個儲存庫只放家庭可見的靜態網頁，不包含婚禮管理專案的資料、試算表、賓客名單與歷史紀錄。

## 更新

編輯 `content.js` 的日期、各場流程、工作項目與更新公告，提交至 `main` 後由 GitHub Pages 自動發布。

「已確認」與「待討論」應保留區別。收到建議後由新人審閱，採納才更改安排，並在 `decisions` 新增說明及修改 `updated`、`version`。

## 回饋

`feedback.email` 可設定新人指定的收件信箱；按鈕會開啟長輩的郵件程式，需按寄出才會送達。`feedback.formUrl` 可設定真正的回饋表單填寫網址。

未設定時只提供複製後傳給新人的方式，頁面會清楚提示沒有自動送出或儲存。長輩不需要 GitHub 帳號。回饋不會自動改動正式安排。

## 資料狀態

- 登記：2027-01-05 已確認。
- 訂婚：2027 年 2–3 月，確切日期待定。
- 迎娶與婚宴：2027 年 8–10 月，確切日期與時段待定。
- 提親：2026 年底前為家庭討論提案。
- 各場流程與人員分工：討論草案。

登記日與規劃區間沿用原專案家庭可見資料；提親與儀式說明參考家庭版儀式底稿，不代表已核准。公開頁面不列家庭財務、內部談話或尚未確認的人選姓名。

## 本機瀏覽

直接開啟 `index.html` 即可。沒有外部相依套件或追蹤碼。
